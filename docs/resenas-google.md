Es una selección estática: no hay conexión API ni actualización automática. Para actualizar, volver a consultar la ficha y modificar `src/data/google-reviews.ts`, incluyendo la fecha. No convertir fechas relativas de Google en fechas exactas. No añadir marcado Review/AggregateRating para obtener estrellas en resultados de búsqueda de nuestra propia empresa. No se carga ningún script externo de Google ni de widgets.
